# 偷菜农场 · Steal Farm — Game Design Document

> 复刻对象：QQ 偷菜 / 开心农场 核心循环（地块经营 + 偷与被偷社交张力）
> 实现形态：纯 HTML5 + JS 单机 H5，模拟邻居（AI）替代真人联机；竖屏移动端优先
> 文档版本：**v0.2（已对齐 team-lead 锁定的实现规格）**｜设计者：design-strategist

> **对齐说明（v0.1→v0.2）**：v0.1 为我方初版提案数值；team-lead 随后锁定了修订规格，engineering-lead 已严格按锁定规格实现 `game.js` 并通过 15 项 headless 冒烟测试。本版 GDD **以实现为权威来源**重写，全部数值取自 `game.js` 常量。与原提案的差异与残留风险见 §14。

---

## 1. 设计支柱 (Design Pillars)

1. **时间驱动的轻松经营**：作物按真实时长生长，点几下一放即可离开，回归"种豆得豆"的舒缓节奏，零操作压力。
2. **社交化的偷与被偷张力**：用 AI 邻居制造"我的菜会被偷 / 我能去偷"的风险与收益，是中段留存的核心钩子。
3. **可积累的正循环**：收获卖钱 → 买种子 / 防盗，形成"种→收→买→守"的自运转经济；防盗（狗+篱笆）是中期必投项。

---

## 2. 核心动词与循环 (Core Verbs & Loop)

五大动词：**种**（买籽播种）/ **养**（除虫除草）/ **收**（成熟收割卖钱）/ **偷**（去邻居农场偷成熟菜）/ **防**（养狗、升篱笆降低被偷）。

- **Moment-to-Moment (0–30s)**：点空地→选种子种下；到点 `MATURE` 高亮→点地块收获；见 ⚠→点除害。
- **Session Loop (3–8 min)**：轮种 9 格 → 顺手去邻居偷 → 回防被偷（攒钱买狗/篱笆）→ 攒钱扩种更贵作物。
- **Long-Term Loop**：堆防盗把被偷压到极低，把邻居菜"薅"成稳定副收益，滚雪球。

---

## 3. 地块系统 (Plot System)

- **数量**：玩家农场固定 **3×3 = 9 格**（邻居农场同为 9 格）。
- **状态机（实现实际状态）**：

  ```
  EMPTY(空地)
    └─[播种]→ PLANTED(已播种·生长中，显示剩余秒数)
              └─[elapsed ≥ grow]→ MATURE(成熟·常驻，可收可偷)
                    ├─[玩家收获/被偷光]→ EMPTY
                    └─[邻居成熟地 stealable≤0 且 20%判定]→ EMPTY(补种)
  ```

  - **无 `WITHERED` / 无成熟窗口**：`MATURE` 常驻直到被收获或被偷空（详见 §14 风险1）。
  - 状态由时间戳派生：`PLANTED` 的 `plantedAt` 与 `grow` 比较；离线重进时 `applyOffline()` 直接把已到点的 `PLANTED` 置 `MATURE`。
- **每格字段**：`state`(EMPTY/PLANTED/MATURE)、`crop`、`plantedAt`、`event`(null/WEED/PEST)、`stealable`(邻居侧可偷余次)、`remaining`(玩家侧剩余产量)。

## 4. 作物表 (Crop Table)

> 数值取自 `game.js` `CROPS`；demo 短时长便于试玩。

| 作物 | 种子价 | 成长(s) | 售价/份 | 单次产量 | 理论净收益 | 净收益/秒 |
|------|-------:|--------:|--------:|---------:|-----------:|----------:|
| 白萝卜 | 10 | 30 | 18 | 3 | +44 | 1.47 |
| 番茄 | 25 | 120 | 45 | 3 | +110 | 0.92 |
| 草莓 | 40 | 180 | 75 | 3 | +185 | 1.03 |
| 南瓜 | 80 | 300 | 160 | 3 | +400 | 1.33 |

- **净收益** = `sell × yield − seed`；**净收益/秒** = 净收益 ÷ 成长秒（不含被偷/事件损耗）。
- **设计观察（非缺陷）**：当前定价下 白萝卜 ROI/秒最高（1.47）且占格短，番茄在"每秒"与"单格总额"上均最弱（被双维度压制）。长作物价值主要体现在"离线挂机"与单次总额。详见 §14 风险2。

## 5. 经济系统 (Economy)

- **初始金币**：`START_GOLD = 100`（取自 `game.js`）。
- **来源**：
  - 收获出售：`gold += sell × max(1, remaining − (event?1:0))`。
  - 偷菜所得：`gold += 邻居作物 sell`（偷 1 份即得该作物 1 份售价）。
- **消耗（槽）**：
  - 买种子：对应 `seed`。
  - 养狗（一次性）：`DOG_COST = 150`。
  - 升级篱笆（一次性）：`FENCE_COST = 200`。
- **不变量**：金币不可为负；买不起的按钮置灰（`gold < cost` 则 disabled）。
- **正循环校验**：100 起 → 白萝卜净 +44/30s → 约 2 轮可买狗(150)；经济自洽不卡死。

---

## 6. 随机事件：杂草 / 虫害 (Random Events)

- **触发**：`growthTick`（每 `GROW_TICK_MS = 1000ms`）对每个处于 `PLANTED` 且无事件的玩家地块，按 `EVENT_CHANCE = 0.01`（每地块每秒 1%）生成 `WEED` 或 `PEST`。
- **影响**：收获时 `y = remaining − (event?1:0)`，且 `y < 1 ⇒ y = 1`（即**减产 1 份，最低保 1 份**）。
- **清除**：玩家点地块→「清除⚠（免费）」，`event=null` 后恢复正常产量。
- **邻居地块不触发事件**（仅玩家侧）。
- **离线简化**：离线期间不补算事件（见 §10、§14 风险5）。

---

## 7. 偷菜机制 (Steal Mechanic)

- **可偷状态**：仅作物处于 `MATURE` 时可偷（`PLANTED` 不可偷；无枯萎窗口）。
- **玩家偷邻居**：
  - 每次点击偷 **1 份**，收益 `gold += 邻居作物 sell`；
  - 邻居每块成熟作物 `stealable` 初始 = `MAX_STEAL_CROP = 2`，每次被偷 `−1`，归零即「已被偷光」不可再偷；
  - **无"单次访问偷菜总量上限"**（实现未设 `MAX_STEAL_PER_VISIT`；跨作物连续偷受 `stealable` 自然限流）。
- **邻居偷玩家**：`neighborStealTick`（每 `STEAL_TICK_MS = 5000ms`）对每个邻居独立判定——若 `rand < effectiveStealProb` 且玩家有 `MATURE` 且 `remaining>0`，随机选一块 `remaining −= 1`（不提示来源）。
- **对称性**：玩家与邻居共用"单块成熟作物最多被偷 2 份"上限。

---

## 8. 防盗机制 (Defense)

`effectiveStealProb = BASE_STEAL_PROB × (hasDog?0.2:1) × (hasFence?0.5:1)`（相乘叠加）。`BASE_STEAL_PROB = 0.25`。

| 防御配置 | 花费 | 被偷概率（每邻居每 5s 判定） |
|----------|------|-----------------------------:|
| 无防御 | 0 | 25% |
| 仅养狗 | 150 | 5% |
| 仅篱笆 | 200 | 12.5% |
| 狗 + 篱笆 | 350 | 2.5% |

- 狗、篱笆均为**单次布尔**（`hasDog`/`hasFence`），非分层升级。
- 3 个邻居各自独立判定，故每 5s 期望被偷次数 ≈ `3 × effectiveStealProb`（ undefended ≈0.75 次/5s，风险偏高；见 §14 风险3）。

## 9. 邻居 AI (Neighbor AI)

- **数量与命名**（取自 `NEIGHBORS`）：`['小明', '小红', '阿强']`，共 **3 个**，行为完全一致（MVP 未区分节奏/偏好）。
- **种植节奏**（`neighborSimTick`，每 `SIM_TICK_MS = 4000ms`）：对每个 `EMPTY` 地块按 30% 概率随机播种一种作物（`plantedAt=now`）；对每个 `MATURE` 且 `stealable≤0` 的地块按 20% 概率清空以补种。
- **来访偷玩家**：见 §7 / §8（每 5s 每邻居按有效概率偷 1 份）。

```js
// 邻居 AI 伪代码（对齐 game.js）
function neighborSimTick() {
  state.neighbors.forEach(function (nb) {
    nb.plots.forEach(function (p) {
      if (p.state === 'EMPTY' && Math.random() < 0.3) {
        p.crop = randCrop(); p.state = 'PLANTED'; p.plantedAt = now();
      } else if (p.state === 'MATURE' && p.stealable <= 0 && Math.random() < 0.2) {
        Object.assign(p, emptyPlot());  // 偷光后概率补种
      }
    });
  });
}
function neighborStealTick() {
  var prob = 0.25 * (hasDog ? 0.2 : 1) * (hasFence ? 0.5 : 1);
  state.neighbors.forEach(function () {
    if (Math.random() < prob) {
      var cands = playerPlots.filter(p => p.state==='MATURE' && p.remaining>0);
      if (cands.length) cands[rand].remaining -= 1;  // 玩家损失，不提示来源
    }
  });
}
```

## 10. 时间与存档 (Time & Save)

- **计时**：全程 `Date.now()` 真实时间戳；状态由 `plantedAt` 派生 → **离线生长天然成立**。
- **离线结算** `applyOffline()`：重进时对每个 `PLANTED` 地块，若 `(now−plantedAt)/1000 ≥ grow` → 置 `MATURE`（玩家 `remaining=yield`，邻居 `stealable=MAX_STEAL_CROP=2`）。**离线期间的事件不补算**（简化）。
- **存档**：`localStorage['stealfarm_save_v1']`，结构如下（取自 `defaultSave`/`normalize`）：

  ```json
  {
    "version": 1,
    "player": {
      "plots": [ { "state":"EMPTY", "crop":null, "plantedAt":0,
                   "event":null, "stealable":0, "remaining":0 } /* ×9 */ ],
      "gold": 100,
      "hasDog": false,
      "hasFence": false
    },
    "neighbors": [
      { "name":"小明", "plots":[ /* 9 格，部分开局即 MATURE 便于偷 */ ] },
      { "name":"小红", "plots":[ /* 9 格 */ ] },
      { "name":"阿强", "plots":[ /* 9 格 */ ] }
    ],
    "savedAt": 1730000000000
  }
  ```

- **健壮性**：`normalize()` 要求 `player.plots` 长度 9、`neighbors` 长度 3，否则回退 `defaultSave()`；字段非法时兜底为 `EMPTY`/0；隐私模式 `localStorage` 异常静默忽略。
- **防作弊提示**：纯前端存档可被手动篡改；正式版应加校验和或移服务端。demo 阶段不做。

## 11. 移动端 H5 交互 (Mobile UX)

- **布局**：竖屏 `viewport` 锁定，内容容器居中；顶栏常驻显示 `💰 金币`、当前视图名、与操作按钮。
- **顶栏按钮**：玩家视图→「🚶去邻居」「🛒商店」「♻️重置」；邻居视图→「🏠回自家」+「重置」。
- **农场网格**：3×3 触屏格子；`PLANTED` 显剩余秒数 + ⚠（有事件），`MATURE` 显 ✓ + 角标（玩家「剩N」/邻居「偷N」）。
- **操作菜单（点地块弹出）**：
  - 玩家 `EMPTY` → 选作物播种（买不起置灰）；
  - 玩家 `PLANTED` → 显示倒计时，有事件则「清除⚠（免费）」；
  - 玩家 `MATURE` → 「收获 ✓（+估算💰）」；
  - 邻居 `MATURE` 且 `stealable>0` → 「偷走 🥷（+sell💰）」。
- **去邻居**：弹层列出 3 邻居及各自可偷成熟地数量，点选进入。
- **商店**：买狗(150)/升篱笆(200)，已拥有或买不起置灰。
- **反馈**：收获/偷成功 `navigator.vibrate(30)` + Toast；按钮触控区充足，支持系统字体缩放。

## 14. 设计对齐说明与残留风险 (v0.1 → v0.2 差异)

**与原提案的主要差异（已按锁定规格落实现）**：
1. 作物定价整体上调（如白萝卜 5→10、南瓜 32→80），初始金币 50→100。
2. 邻居由「老王/小美(阿强可选)」改为固定 **3 个**：小明/小红/阿强，且节奏统一（无独立间隔/偏好）。
3. 防盗由「狗50 + 篱笆分层 40+80」改为「狗150(×0.2) + 篱笆200(×0.5)」单层布尔。
4. 事件由「每周期 30% 触发、减产减半」改为「每 tick 1% 触发、减产 −1（保底 1）」。
5. 移除「成熟窗口/枯萎」与「每访偷菜上限 3」：`MATURE` 常驻，偷菜仅受单块上限 2 约束。

**残留设计风险（建议后续评审关注）**：
- **R1 时间衰减缺失**：`MATURE` 常驻且无枯萎，失去"不收就被偷光/枯掉"的紧迫感；结合 R2，玩家可无限挂机成熟菜。
- **R2 作物 ROI 错位**：白萝卜 ROI/秒(1.47)最高且占格短，番茄被双维度压制；长作物价值仅体现在离线/单格总额。建议后续用"枯萎窗口"或调价恢复长作物耐心溢价。
- **R3 无防御期被偷偏快**：undefended 每 5s 期望被偷 ≈0.75 次（3 邻居×25%），单格产量 3 约 20s 可被掏空；买狗需 150（起步 100 需先回血）。早期间 tension 偏硬，建议评估是否下调 `BASE_STEAL_PROB` 或提速买狗。
- **R4 无每访偷菜上限**：玩家可在一屏内把某邻居多块成熟菜连偷（每块≤2 次）；当前靠 `MAX_STEAL_CROP=2` + 邻居成熟地数量限流，若邻居成熟地偏多，偷收益可能偏高。建议后续加 `MAX_STEAL_PER_VISIT`。
- **R5 离线事件不补算**：离线期间长成长作物若本应触发事件，重进后不计；属实现简化，评审需知会。

**候选缓解方案（未来平衡 pass，当前未实现，供评审）**——工程侧确认 R1/R4/R5 保持现状，仅 R2/R3 值得 revisit：
- **R2 候选**：番茄作为中段作物缺乏差异化卖点，建议给番茄一个「批量/连收」类特性（如一次收相邻同作物多格），而非改数值；保持短作物 ROI/秒最高的设计意图。
- **R3 候选**：新手保护——开局前 N 分钟 `effectiveStealProb × 0.5`（可新增 `NEWBIE_GRACE_MS` 常量），缓解买不起狗/篱笆前的被动体验。
- 所有平衡常量均已集中在 `game.js` 顶部具名（`BASE_STEAL_PROB`/`DOG_COST`/`FENCE_COST`/`EVENT_CHANCE`/`MAX_STEAL_CROP` 等），将来实验调参改一处即可，无需动逻辑。

《F-1赛车》（日文名：F-1レース，英文名：F-1 Race）是由HAL研究所开发、任天堂发行的一款经典竞速游戏。该游戏于1984年在日本的红白机（Famicom）平台首次发布，随后于1990年在Game Boy平台推出，并在1991年登陆欧美市场。

在游戏中，玩家驾驶一辆红色的F1赛车，在多条风景各异的赛道上进行比赛。游戏采用类似于Namco的《Pole Position》的视角和玩法，玩家需要在限定时间内完成每条赛道的两圈比赛，以解锁下一条赛道。游戏设有三种难度级别，每个级别包含五条赛道，难度逐渐增加。

游戏的操作简单直观，赛车配备了两速手动变速箱，分别为“低速”（LOW）和“高速”（HI）。玩家需要在弯道和直道之间合理切换速度，以保持最佳行驶状态。与其他赛车或赛道边缘物体碰撞会导致赛车损毁并重生，浪费宝贵的时间。此外，玩家需注意在弯道处的速度控制，过快可能导致车辆打滑，影响比赛成绩。

Game Boy版本的《F-1赛车》引入了四人联机模式，玩家可以通过四人适配器与朋友们一起竞速。该版本还增加了马里奥、路易吉、碧奇公主等任天堂经典角色，他们会在赛道终点为玩家加油助威。

《F-1赛车》凭借其简单易上手的操作和富有挑战性的赛道设计，成为了当时备受欢迎的竞速游戏之一。

# 任务列表 (Tasks)

- [ ] 任务 1: 初始化游戏画布和基础资源
  - [ ] 子任务 1.1: 调整 `index.html` 中的 Canvas 大小以适合游戏画面（例如 800x600）。
  - [ ] 子任务 1.2: 清空现有的 `script.js`。
  - [ ] 子任务 1.3: 设置游戏主循环 (Game Loop, 使用 `requestAnimationFrame`)。

- [ ] 任务 2: 实现赛道绘制和滚动效果
  - [ ] 子任务 2.1: 在 Canvas 上绘制赛道背景（草地和柏油路面）。
  - [ ] 子任务 2.2: 绘制赛道两侧的边界线或红白相间的路肩。
  - [ ] 子任务 2.3: 实现基于当前速度的赛道向下滚动动画效果，产生前进的错觉。

- [ ] 任务 3: 实现玩家赛车的渲染与控制
  - [ ] 子任务 3.1: 绘制一个代表玩家 F1 赛车的图形（可以用简单的几何图形组合）。
  - [ ] 子任务 3.2: 监听键盘事件（左、右箭头键）。
  - [ ] 子任务 3.3: 根据按键更新赛车的 X 坐标，并限制其不能移出赛道边界。

- [ ] 任务 4: 实现变速机制 (LOW / HI)
  - [ ] 子任务 4.1: 监听键盘事件（L 和 H 键）。
  - [ ] 子任务 4.2: 维护一个内部的速度变量。当切换档位时，速度变量应平滑过渡到目标档位的最大速度。
  - [ ] 子任务 4.3: 将该速度变量应用于赛道滚动速度和障碍物移动速度。
  - [ ] 子任务 4.4: 在屏幕上显示当前的档位和模拟速度。

- [ ] 任务 5: 实现障碍物生成与碰撞检测
  - [ ] 子任务 5.1: 随机在赛道上方生成代表其他赛车的方块。
  - [ ] 子任务 5.2: 让这些方块向下移动（速度基于游戏基础速度 + 障碍物自身相对速度）。
  - [ ] 子任务 5.3: 实现 AABB (轴对齐包围盒) 碰撞检测。
  - [ ] 子任务 5.4: 当检测到玩家赛车与障碍物碰撞时，执行碰撞逻辑（例如：速度降为0，闪烁，重新开始当前跑道等）。

# 任务依赖 (Task Dependencies)
- 任务 2 依赖于 任务 1。
- 任务 3 依赖于 任务 1。
- 任务 4 依赖于 任务 2 (因为速度影响滚动)。
- 任务 5 依赖于 任务 2 和 任务 3。

# F-1赛车 游戏规格说明 (Spec)

## 为什么 (Why)
用户希望在当前目录 `/Users/hooksvue/Desktop/front-end-navigation-bar/code/f1_race` 下创建一个名为《F-1赛车》的游戏。目前我已经创建了一个简单的信息展示页面和一个粗糙的占位方块演示，但用户明确表示不满意，要求真正地“生成游戏”。因此，我们需要构建一个具有基本可玩性的、基于 Web 的 2D 赛车游戏原型，以满足用户对“游戏”的期望。

## 改变了什么 (What Changes)
- 使用 HTML5 Canvas 和 JavaScript (不使用复杂框架，以保证轻量和易于理解) 构建一个自上而下的 2D 赛车游戏。
- 实现一条可以无限滚动或循环的赛道。
- 实现玩家赛车的渲染、左右移动控制。
- 实现基本的变速机制（低速/高速档位切换）。
- 实现简单的障碍物（其他车辆或赛道边缘）生成和基本碰撞检测。
- 移除之前创建的粗糙占位演示代码，替换为实际的游戏逻辑。

- 受影响的代码：主要修改 `/Users/hooksvue/Desktop/front-end-navigation-bar/code/f1_race/script.js` 和 `/Users/hooksvue/Desktop/front-end-navigation-bar/code/f1_race/style.css`，并微调 `index.html` 以适应完整的 Canvas 游戏区域。

## 新增需求 (ADDED Requirements)
### 需求: 2D 赛车游戏核心玩法
系统 SHALL 提供一个基于浏览器的 2D 赛车游戏体验。

#### 场景: 成功启动游戏
- **WHEN** 用户打开页面。
- **THEN** 游戏画布应该显示赛道，玩家的赛车位于赛道底部中央。

#### 场景: 赛车移动控制
- **WHEN** 用户按下左右方向键。
- **THEN** 赛车应在赛道范围内平滑地左右移动。

#### 场景: 赛车变速控制
- **WHEN** 用户按下 'L' 键或 'H' 键。
- **THEN** 赛车应切换到低速或高速档，游戏世界（赛道和障碍物）向下滚动的速度应相应改变，模拟赛车加速/减速。

#### 场景: 障碍物与碰撞
- **WHEN** 赛车行驶时。
- **THEN** 赛道上方应随机生成障碍物（代表其他车辆）并向下移动。
- **WHEN** 玩家赛车与障碍物或赛道边缘发生重叠。
- **THEN** 触发碰撞事件，游戏暂停或重置赛车状态，并可能显示“碰撞”提示。
